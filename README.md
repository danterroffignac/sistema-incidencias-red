# Sistema de Registro de Incidencias de Red
Sistema de registro de incidencias tecnicas para la rede de cable de GrupoMultimedios - TPI Organizacion Empresarial, UTN.
# Descripcion
Se busca implementar un sistema de registro de incidencias para el control de fallas en un canal de cable . El objetivo es que al tener los datos cargados en el programa se puedan prever incidencias a futuro y así reducir los reclamos por mal funcionamiento del servicio.
