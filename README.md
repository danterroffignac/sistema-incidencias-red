# Sistema de Registro de Incidencias de Red
Sistema de registro de incidencias técnicas para la red de cable de GrupoMultimedios - TPI Organización Empresarial, UTN.
## Descripción
Se busca implementar un sistema de registro de incidencias para el control de fallas en la red de cable de la empresa. El objetivo es que al tener los datos cargados en el programa se puedan prever incidencias a futuro y así reducir los reclamos por mal funcionamiento del servicio.
